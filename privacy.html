What this prototype stores

The bag, saved designs, wishlist, demo membership, and waitlist addresses are stored in this browser. They are not sent to a server unless a form endpoint is configured. This repository does not include analytics, advertising pixels, or payment fields.

Waitlist

If the waitlist endpoint in the configuration is empty, an email address stays on the device. If an endpoint is set, the address is posted to that URL as JSON. Do not put a secret in the configuration file.

Payments

No card number is collected here. A future checkout is intended to run on Shopify.

Contact

Add a real contact address before publication. None is printed here, so this prototype does not publish personal information.
